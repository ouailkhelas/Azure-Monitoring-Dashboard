# Azure Monitoring Dashboard

Enterprise monitoring solution using Terraform, Azure Monitor, Log Analytics, and Azure RBAC.

---

# 🚀 Overview

Hybrid monitoring approach combining:

- Terraform infrastructure deployment
- Azure Portal customization
- KQL query development
- RBAC governance
- Automated alerting

---

# ⚙️ Features

## Azure Monitor Workbooks
- VM performance dashboards
- Network monitoring views
- Cost tracking dashboards

---

## Alerting
- CPU usage alerts
- Memory pressure alerts
- Disk space monitoring
- Budget threshold alerts

---

## RBAC Governance
- Monitoring Contributor roles
- Monitoring Reader access

- IAM role assignments
- Access auditing
